LLM Evaluation Framework

Could We Have Used an Existing Tool?

promptfoo is an open-source LLM evaluation framework that offers:

  • Multi-model testing with custom evaluation criteria
  • LLM-as-judge for pairwise comparisons
  • Built-in web viewer and reporting

Reality check: promptfoo came to attention late in the game. Even if discovered earlier, steep learning curve to harness appropriately for our specific needs (bidirectional testing, custom HTML reports, statistical aggregation).

Future work: Should be on radar for VEuPathDB AI projects.
