Two-Step Prompting Approach

Step 1: Individual Experiments

Each experiment summarized independently:

  • One-sentence summary of gene behavior
  • Biological importance score (0-5)
  • Confidence score (0-5)
  • Experiment keywords
  • Optional notes for caveats

Parallel processing with structured JSON output

Step 2: Consolidation

High-confidence summaries combined:

  • Filter: biological_importance > 3 AND confidence > 3
  • Group filtered experiments into topics
  • Generate gene-specific headline
  • Create ~100 word summary with HTML formatting

Developed iteratively with GPT-4o via API
